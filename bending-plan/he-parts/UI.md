# כשפות — מסכים ו-HUD

כל מה שכאן בנוי מערכת רכיבי ה-UI של Enhanced, שהועתקה אל `bending.client.screen`: `CreatorUi.BigButton` (רכיב הכרטיס: סמל או פנים, תווית, שורת משנה, צבע, מצבי נבחר/מואר), `EditorTab.cards(...)` (הרשת המחולקת לעמודים), `Popup`,
`PreviewPuppet` (`RemotePlayer` שמצויר בתוך הממשק בעזרת `EntityRenderDispatcher` ומונפש בעזרת ממשק התצוגה המקדימה של המאנפש), `CatalogSearch` (חיפוש בשתי שפות עם איחוד אותיות עבריות), `HudDraw.visual` (פריסה מימין לשמאל בכוח, בעזרת ICU
`Bidi`), מסכי ההגדרות שנוצרים אוטומטית (`ConfigScreen`, `ConfigSectionScreen`, `ConfigListScreen`), ותבנית ה-HUD
מסוג `LayeredDraw.Layer` שנרשמת דרך `ClientRegistrar.guiLayer`. אף אחד מהמסכים לא עוצר את המשחק.

**עברית.** לכל מסך יש פריסה מימין לשמאל כש-`Language.getInstance().isDefaultRightToLeft()` מחזיר אמת: העמודות
הפוכות (התצוגה המקדימה עוברת לימין, הרשימות לשמאל, הטקסט מיושר לימין), השורות נפרסות בעזרת `HudDraw.visual`
כך ששורה שמתחילה בשם מקש לטיני (`[X]`) עדיין זורמת מימין לשמאל, והיחידות יושבות בתוך התרגום
(`hud.bending.seconds` = `%s ש׳`), כמו שלמד Enhanced. המספרים נשארים בספרות לטיניות. שמות המקשים מ-`getTranslatedKeyMessage()`
נשארים כפי שהמשחק נותן אותם.

## 1. מקשים ואיך המסכים נפתחים

| מקש | ברירת מחדל | פעולה |
|---|---|---|
| `key.bending.slot_1..4` | **X, C, Left Alt, K** | משבצות סידור הקרב; התכופפות + מקש היא הווריאציה (הלקוח שולח את דגל ההתכופפות יחד עם הלחיצה, לכידת `PRESS_SNEAK` של Enhanced) |
| `key.bending.menu` | **O** | פותח את **מסך הכשפות** (לשוניות); התכופפות + O מחליפה מראה מיד |
| (אין) | לחיצה ימנית | מגילת האלמנטים (מסך הבחירה), שק המים (מילוי), הגלשן (פתיחה/סגירה) |
| `key.bending.menu` בזמן שמשבצת מוחזקת? | — | אין צירופי מקשים מעבר להתכופפות |

הקטגוריה `key.categories.bending` = "Bending" / "כשפות". ההקשר `IN_GAME` לכולם (כך שהתנגשות עם המקשים של Enhanced תופיע
בבקרים: אין אף אחת כזו כברירת מחדל).

## 2. מסכים

### 2.1 בחירת אלמנט — בחירת אלמנט (`ElementChoiceScreen`)

נפתח על ידי מגילת האלמנטים (שרת ← `ElementScreenPayload`), או על ידי `/bending choose`. ארבעה כרטיסים, תצוגה מקדימה וכפתור אישור.

```
┌──────────────────────────────────────────────────────────────────────────┐
│                         Choose your element                              │
│   ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐    ┌───────────┐  │
│   │  ▲ EARTH │ │  ◎ AIR   │ │  ≈ WATER │ │  ♦ FIRE  │    │           │  │
│   │  [Toph]  │ │ [Tenzin] │ │ [Katara] │ │  [Zuko]  │    │  (3D you  │  │
│   │ Rock Throw│ │ Air Blast│ │Water Shot│ │ Fireball │    │  in the   │  │
│   │ Earth Wall│ │Air Shield│ │ Healing  │ │Fire Whip │    │  element's│  │
│   │ Earth Arm.│ │Air Scoot.│ │Ice Knives│ │ Lightning│    │  default  │  │
│   │  Looks: 6 │ │  Looks: 6│ │  Looks: 4│ │  Looks: 5│    │   look)   │  │
│   └──────────┘ └──────────┘ └──────────┘ └──────────┘    └───────────┘  │
│        Strong, rooted. Earth Kingdom.  Water is strong against fire.      │
│                  [ Become an Earthbender ]        [ Not now ]             │
└──────────────────────────────────────────────────────────────────────────┘
```

* הכרטיסים הם `BigButton`ים בגודל 92 × 110 (מוגבלים לרוחב: `cardW = clamp((width−24−3·GAP)/4 … )`, המתכון של `SerumScreen`
  לשלושה כרטיסים, שהורחב לארבעה), ובכל אחד **סמל האלמנט** (6.1), שמו מודגש
  בצבע האלמנט, **הפנים** של מראה ברירת המחדל (`PlayerFaceRenderer`), שלוש יכולות פתיחה באפור, "מראות: n"; כרטיס נבחר
  מקבל מסגרת כפולה בזהב; ריחוף העכבר מפעיל פצפוץ קצר של חלקיקי האלמנט מאחורי הכרטיס (ב-`CreatorUi`
  אין חלקיקים: זה להקת ספרייטים של `GuiGraphics` עם 6 גרגרים, זולה).
* **התצוגה המקדימה** (`PreviewPuppet`, גובה 96 פיקסלים) מראה **אתכם** במראה ברירת המחדל של האלמנט הנבחר, מבצעים
  את עמידת ההמתנה של האלמנט (`previewHold` של `EARTH_IDLE` וכן הלאה) ובכל 4 ש׳ את תנועת הפתיחה שלו (`previewCast`).
* **שורת התיאור** (2 שורות לכל היותר, `font.split`) ו**רמז היריבות**.
* **להפוך** שולח `ElementChoicePayload(element)`; **לא עכשיו** סוגר (המגילה נשמרת). המקשים 1–4 בוחרים, Enter
  מאשר (כמו ב-`SerumScreen`).
* **עברית (מימין לשמאל):** הכרטיסים זורמים מימין לשמאל (אדמה בצד ימין), התצוגה המקדימה יושבת **בשמאל**, הטקסט
  מיושר לימין:

```
┌──────────────────────────────────────────────────────────────────────────┐
│                           בחרו את האלמנט שלכם                            │
│  ┌───────────┐    ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐    │
│  │           │    │   אש ♦   │ │  מים ≈   │ │ אוויר ◎  │ │  אדמה ▲  │    │
│  │ (תצוגה    │    │  [זוקו]  │ │ [קטארה]  │ │ [טנזין]  │ │  [טוף]   │    │
```

### 2.2 מסך הכשפות — מסך הכשפות (`BendingScreen`, מקש O)

מסך אחד, ארבע לשוניות (הפריסה של `HeroEditorScreen` של Enhanced: לשוניות ב-y 16, עמודת תצוגה מקדימה שמאלית `left() =
clamp(width/3, 92, 160)`, עמוד התוכן מימינה לה, ושורת מצב במקום הכותרת במשך 6 ש׳ אחרי
פעולה). ה**כותרת העליונה** מראה את סמל האלמנט, "כשף אדמה", **SP** ו-**ES**: `✦ 12 SP   ◆ ES 23`.

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ▲ Earthbender                ✦ 12 skill points   ◆ strength 23           │
│ [ Skill Tree ] [ Loadout ] [ Looks ] [ Water ]            (tab buttons)  │
│ ┌────────────┐ ┌──────────────────────────────────────────────────────┐  │
│ │            │ │                                                      │  │
│ │  3D you    │ │                 (tab content)                        │  │
│ │  (turn by  │ │                                                      │  │
│ │  dragging) │ │                                                      │  │
│ │            │ │                                                      │  │
│ │ Stand Walk │ │                                                      │  │
│ │ Run  Cast  │ │                                                      │  │
│ └────────────┘ └──────────────────────────────────────────────────────┘  │
│                                   [ Done ]                                │
└──────────────────────────────────────────────────────────────────────────┘
```

התצוגה המקדימה מנגנת את עמידת ההמתנה של האלמנט; **Cast** מנגן את תנועת היכולת הנבחרת (`previewCast`) כדי שאילון יראה את
המהלך לפני שיפתח אותו. לשונית **המים** מופיעה רק לכשפי מים (2.6).

#### 2.2a לשונית עץ הכישורים — עץ הכישורים

**גרף של כרטיסים** שמצויר על קנבס שאפשר לגלול (גוררים כדי להזיז, גלגלת כדי לשנות זום 0.75–1.25): השורש למעלה, הדרגות
מתחתיו, ו**מחברים** כקווים בעובי 2 פיקסלים בצבע האלמנט (מוארים כשאפשר לפתוח את הצאצא, אפורים כשהוא נעול, זהובים כשהוא
פתוח). כל צומת הוא `BigButton` בגודל 76 × 40 עם **סמל** היכולת (6.2), שמה, ו**שורת משנה**: `Unlocked ·
M 4` או `3 SP` או `Needs Rock Throw M2`. בחירה בצומת ממלאת את **לוח הפרטים** מימין (או מתחת במסכים צרים):
